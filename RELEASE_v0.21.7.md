# Game2 v0.21.7 — WaveSpeed Photo Delivery Fix

## Что исправлено

1. **Вечная загрузка фото в чате**
   - очередь доставки теперь оборачивает генерацию/сохранение в ограниченное ожидание;
   - если WaveSpeed уже сгенерировал изображение и оно есть в локальном кэше, чат может показать кадр сразу, даже если запись события в историю задержалась;
   - pending-сообщение больше не должно зависать бесконечно без перехода в `ready` или `failed`.

2. **Совместимость результата WaveSpeed**
   - Worker принимает как обычный polling-ответ, так и быстрый `sync`-ответ с уже готовым изображением;
   - обработаны варианты `outputs`, `output`, URL и base64-ответов;
   - поддержаны terminal-статусы `completed`, `succeeded`, `success`.

3. **Нормализация фотопромптов**
   - все промпты для Александры теперь принудительно нормализуются в реалистичный `selfie` или `mirror selfie`;
   - если пользователь просит полный рост / зеркало, используется `mirror selfie`;
   - в остальных случаях используется `smartphone selfie`;
   - в инструкциях GPT усилен запрет на нереалистичные / стилизованные изображения.

## Что не менялось

- `SCHEMA_VERSION = 4`
- Firestore/Auth/App Check контракты
- Экономика, память, эмоции и логика общения
- WaveSpeed LoRA-маршрут остался тем же, без возврата старых провайдеров

## Локальные проверки

Запущено в этом окружении:

```bash
npm test
```

Все встроенные тесты прошли успешно.

`npm run typecheck` / `npm run build` здесь не подтверждены, потому что в окружении отсутствуют установленные npm dev-dependencies (`vite`, `@vitejs/plugin-react`, `vite/client`).
