# Release v0.20.22

## WaveSpeed identity-sheet priority + more attractive intimate prompts

- WaveSpeed now uses only `identity-sheet.jpg` when it exists.
- `avatar.jpg` is sent to WaveSpeed only as a fallback when no identity sheet is available.
- Improved WaveSpeed prompt construction for intimate photos so medium/high suggestive requests aim for a more attractive, flattering and pleasing composition instead of a technical reference-shot feel.
- Ordinary non-explicit photos remain natural and casual.
