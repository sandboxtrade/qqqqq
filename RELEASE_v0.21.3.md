# Game2 v0.21.3 — People, My Profile, Virtual Economy

База: полный локальный `Game2-Alexandra-v0.21.2-Z-Image-Turbo-LoRA.zip`.

- Снята вкладка «Рядом» вместе с автоматической генерацией сцены и маршрутом `/alexandraPresencePhoto`.
- Вкладки: Чат / Люди / Соцсеть / Профиль. Настройки доступны через верхнюю кнопку.
- Реестр персонажей больше не игнорирует `characterId`. Сейчас фактически один персонаж — Александра; фиктивных девушек нет.
- Добавлено оформление анкеты пользователя, локальная/Firestore-персистенция и opt-in к будущему обнаружению в соцсети.
- Добавлена виртуальная валюта: стартовый баланс 3000, расходы на подарки и переводы, атомарность Firestore-транзакции, защита повторного списания по ID, журнал последних операций. Ответ персонажа остаётся GPT-решением без принудительного прироста близости.
- Ссылка на LoRA Александры внесена исключительно в серверный Worker. API-ключи по-прежнему хранятся только в секретах Worker.
- GPT-диалог, signed GPT-photo decision, WaveSpeed LoRA чат-фотографии, память, механика отношений, schema 4 и старый код неактивных провайдеров сохранены.

Ограничения первого этапа:
- У персонажей **пока нет** механизма сканирования анкет и самостоятельного первого контакта на основе заинтересованности.
- Баланс нельзя покупать/пополнять, серверного защищённого ledger нет; Firestore user-write rules позволяют владельцу документа изменять баланс вручную.
- Сборка приложения на реальные npm-зависимости в этом окружении недоступна (offline npm cache), поэтому браузерный интеграционный тест не выполнен.
