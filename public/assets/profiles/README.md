# Character profile photos

Each character has a stable asset folder:

- `yuzuki/`
- `mika/`
- `rin/`
- `lea/`
- `sofia/`
- `eva/`
- `nora/`

Expected filenames:

- `avatar.jpg` — profile/chat avatar and profile hero photo.
- `01.jpg`, `02.jpg`, `03.jpg` — gallery photos in order.

Missing files are handled by the UI with a neutral photo placeholder. Adding a file with the expected name makes it appear without changing TypeScript code.
