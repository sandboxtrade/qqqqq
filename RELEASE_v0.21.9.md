# Game2 v0.21.9 — Firebase turn stability

База: v0.21.8, полный накопительный проект.

Изменения:
- `src/storage/repository-factory.ts`: больше нет универсального 8-секундного `bounded()` для любой операции. Чистые чтения ограничены 30 секундами, а транзакции и записи не оставляются работать незаметно после фиктивного тайм-аута.
- `src/storage/firestore-operation-policy.ts`: консервативная классификация операций и именные ошибки с исходным Firebase code.
- `src/app/store.ts`: transient `unavailable`/`deadline-exceeded` повторяются с тем же ID без повторной загрузки всего персонажа; конфликты revision всё ещё делают bootstrap.
- `src/core/async.ts`: текст ошибки различает Firestore-операции, не утверждает что у пользователя пропал интернет.
- `src/ui/SettingsScreen.tsx`: отображает v0.21.9 для диагностики старой сборки на телефоне.

Не изменяли: Firestore схему и пути, Firebase Auth/App Check, память, эмоции, экономику, Web UI чата, WaveSpeed и LoRA, локальное хранение фотографий.

### Диагностика
Текст со скриншотов `Нет связи с Firebase. Проверь интернет и повтори отправку.` встречался в v0.21.6/0.21.7, но заменён уже в v0.21.8. Убедись, что в настройках на устройстве отображается 0.21.9.
