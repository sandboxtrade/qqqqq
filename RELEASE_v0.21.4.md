# Game2 v0.21.4 — per-character photo no-refusal mode

База: полный ZIP v0.21.3. Все файлы проекта и прошлые функции сохранены.

- В каталоге «Люди» добавлен переход в настройки именно выбранного персонажа. При переключении персонажа редактор сбрасывает локальные черновики, исключая смешивание настроек.
- В «Настройки → Фотографии» добавлен переключатель **Безотказный режим** (по умолчанию выключен).
- Настройка уже хранится в существующем `editableContext.photoNoRefusalMode` отдельно для каждого `characterId` через Firebase; формат `SCHEMA_VERSION=4` не менялся.
- Активный `cloudflare/worker.js` теперь действительно учитывает `photoPolicy.noRefusalMode` при обработке прямого запроса фото и продолжения фотосерии. Игровые пороги доверия/близости и настроение при включённом режиме не запрещают допустимый снимок. Обычные диалоги, эмоции и стадия отношений не меняются.
- Если модель вернула отказ и не составила промпт, Worker делает отдельный GPT-запрос исключительно за фотопромптом. Worker не сочиняет сцену самостоятельно. Промпт подписывается как в v0.21.3; запрос на WaveSpeed по-прежнему защищён подписью, Firebase Auth и App Check.
- Технические ошибки, лимиты и ограничения внешнего генератора не обходятся. Активное явно выраженное требование «стоп/пауза» в текущей реплике не превращается в запрос фото. Настройка не влияет на согласие на интимное взаимодействие.
- Старые провайдеры сохранены в исходниках, активная генерация через WaveSpeed Z-Image Turbo LoRA `g2girl01`.
- Никаких новых ключей и серверных настроек; **на GitHub / Cloudflare ничего не отправлялось**.

Для тестов: `npm test`, для полной сборки — `npm ci && npm run verify` в среде с доступом к npm.
