# Game2 v0.21.8 — Chat Reliability / Office Outfit Continuity

Накопительная версия на основе **v0.21.7**. Никаких изменений на GitHub и Cloudflare автоматически не выполнялось.

## Проблема Firebase / отправки сообщений

Из анализа исходников v0.21.7 подтверждены две рискованные части:

1. `FirestoreCompanionRepository.loadRuntimeState()` безусловно выполнял транзакцию даже для обычного чтения состояния и мира. Это увеличивает сетевую задержку и чувствительность к конфликтам транзакций.
2. Клиентский `sendTurn` обрывался через 40 секунд, хотя один запрос GPT также мог занимать до 40 секунд, **без учёта** нескольких чтений Firebase, подготовки токенов и финальной записи состояния.

В v0.21.8:

- обычное чтение состояния выполняется параллельными `getDoc` без транзакции;
- транзакционная перепроверка/самовосстановление ревизий применяется только при обнаружении несоответствия между документами;
- сообщения в разных вкладках одного браузера сериализуются через Web Locks (если доступны);
- временные ошибки `unavailable`, `aborted`, `deadline-exceeded` и конфликты ревизий могут повторяться до двух раз с **тем же ID сообщения**; это сохраняет идемпотентность;
- клиентский общий предел отправки поднят до 85 секунд, отдельно от 40-секундного ожидания GPT Worker;
- ошибки Firebase показывают код, а консоль сообщает код сбоя (без текста сообщений и ключей);
- экономический контекст теперь загружается параллельно другим контекстным запросам, а не отдельным последовательным ожиданием.

**Граница проверки:** точный FirebaseError в работающей версии неизвестен без логов браузера и Firebase. Изменения устраняют обнаруженные проблемные места кода, но не являются доказательством, что любой возможный FirebaseError устранён. Если ошибка продолжится, важно сохранить конкретный `[code]` и первую строку лога `[Game2] turn delivery failed`.

## Фиксация офисной одежды

Рабочий комплект Александры строго закреплён на интервал офисной смены (по текущему расписанию игры):

- белая офисная рубашка с немного расстёгнутыми **средними** пуговицами;
- чёрная приталенная офисная юбка-карандаш;
- чёрные туфли на каблуках.

Режим одежды вычисляется из **расписания смены**, а не из временного `currentActivity=chatting`, поэтому несколько фотографий подряд в переписке используют один комплект. GPT может менять позу, кадр, освещение и мелкие действия. Дома одежда не закреплена. Дополнительных полей Firestore не требуется (`SCHEMA_VERSION=4`).
